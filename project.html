Cafeteria App

A desktop cafeteria app built for a school, with a customer side for browsing and buying and a dashboard for managers.

View code on GitHub

Screenshots

Overview

The Cafeteria App is a desktop application I built as a school project. Customers log in, browse the menu, add items to a cart and purchase, and can look back at their orders and profile. A separate manager dashboard lets managers add stock and look after the cafeteria side. The screens were designed in Scene Builder, and the data is stored in PostgreSQL.

Problem I solved

Ordering at a school cafeteria usually means queues and manual tracking. This app lets customers choose and purchase from their own screen, while managers can add stock and keep things running from one place.

Features

  • Log in to a personal account
  • See your account balance
  • Browse the menu
  • Add items to a cart and purchase
  • Review past orders and your profile
  • Manager dashboard for adding stock and managing the cafeteria

Technologies used

  • Java
  • JavaFX
  • Scene Builder
  • NetBeans
  • PostgreSQL

What I learned

  • Scene Builder let me design screens by dragging things around, but every button and field still had to be wired to Java code. That taught me how an interface and the logic behind it actually talk to each other.
  • Connecting a desktop app to PostgreSQL meant thinking about users, menu items, carts and orders as separate tables that relate to each other.
  • Building a manager dashboard next to the customer screens showed me that different users need different views of the same data.
  • On a project this size, keeping screens, controllers and database code in separate places stopped one change from breaking something unrelated.
