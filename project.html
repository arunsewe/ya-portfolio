TastyBites

A full-stack customer records manager for a restaurant, built with a React frontend, a NestJS backend and Nginx.

View code on GitHub

Screenshots

Overview

TastyBites Customer Records Manager is a web application for keeping track of a restaurant’s customers and their orders. A React frontend talks to a NestJS backend, and the app is served with Nginx.

Problem I solved

Customer details and orders are easy to lose track of when they live in notebooks or scattered files. TastyBites keeps every customer and their orders in one place, where staff can find, update and add to them quickly.

Features

  • Register a customer with name, date of birth and home address
  • See every customer in one list
  • Edit or delete a customer record
  • Add an order for a customer
  • View a customer’s orders

  • Nginx
