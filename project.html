Email Newsletter System

A server-side application for managing subscribers and sending newsletters to them from one place.

View code on GitHub

Screenshots

Overview

This project is an email newsletter system. Admins manage a list of subscribers, write a newsletter, and send it to everyone on the list. It runs on the server, so sending, storage and unsubscribes are handled in one place.

Problem I solved

Sending updates to a group of people one email at a time is slow and easy to get wrong. People get missed, lists go out of date, and there is no record of what was sent. This system keeps the list and the sending process in one reliable tool.

Features

  • Add, edit and remove subscribers
  • Write and send a newsletter to the whole list
  • Unsubscribe handling
  • Record of campaigns sent
